# 宵宮の金魚すくい

夏の昼の金魚すくい。水面を **Tessendorf の波スペクトルから GPU 上の FFT で毎フレーム逆変換**して描いています。

<https://kanade0525.github.io/kingyo-sukui/>

遊び方は、押している間だけポイが沈む、それだけです。金魚の下に入れて持ち上げると、手元の器に入ります。

---

## 水面の作り

水面の高さ場は 2 つを足し合わせています。**定常な波**と、**その場で立った波紋**は性質が違うので、別々に解いています。

### 1. 定常な波 — FFT（`assets/js/ocean.js`）

Tessendorf の海面法をそのまま小さな舟に持ち込んでいます。

```
P(k) = A · exp(-1/(kL)²) / k⁴ · |k̂·ŵ|² · exp(-k²l²)      L = V²/g
h(k,t) = h0(k)·e^{iωt} + conj(h0(-k))·e^{-iωt}
ω = √(g·k·tanh(k·H))
```

- `h0` は起動時に CPU で一度だけ作ります。風速か風向を変えた時だけ作り直します
- 毎フレーム、時刻 `t` のスペクトルと choppy 変位 `Dx, Dz` を出し、**GPU のバタフライ演算で逆 FFT**します
- **MRT（`drawBuffers` 2 枚）で高さと変位 X / Z を 1 パスで同時に変換**するので、N=128 でもバタフライは 14 パスで済みます
- 分散関係には `tanh(kH)` を入れてあります。ただし引数は 10 で頭打ちにしています。実装によっては内部で `e^(2x)` を通るため、`kH > 100` で `Inf/Inf = NaN` になり、FFT 全体が壊れます

振幅は **実効「傾き」で正規化**しています。水面の見え方（反射のちらつき、底の揺らぎ、コースティクス）を決めるのは波高そのものではなく傾きなので、こちらを揃えたほうが縮尺を変えても崩れません。

Phillips は `1/k⁴` を持つので、係数 `A` の意味が波数の縮尺で何桁も変わります。海（波長 100m 級）向けの `A` をそのまま 1m の舟に使うと波が消えます。`A` には形だけ決めさせ、大きさは一度に正規化しています。

### 2. 波紋 — 波動方程式（`assets/js/ripple.js`）

FFT はスペクトルを逆変換しているだけなので、後から「ここで水を叩いた」を混ぜ込めません。波紋だけ 256² の格子で別に解いています。

```
h[n+1] = 2h[n] − h[n−1] + K·∇²h[n]
```

壁は Neumann（傾き 0）にして反射させています。たらいの中の波は端で跳ね返るので、これが無いと端で消えて嘘くさくなります。

### 3. 光（`assets/js/sky.js`）

光源は太陽ひとつ。方向の揃った光でないと、水底のコースティクスも水面のきらめきも芯が出ません。
時刻（0〜24 の実数）を渡すと、太陽の高度・方位・色、空の三色、霞み、露出が決まります。設定パネルの「時刻」で動かせます。

屋台の向きを 95° 回してあります。これを 0 にすると、ほぼ真上から覗く構図では太陽の照り返しがそのまま水面の中央に座り、白い靄で底が見えなくなります。

### 4. 水底のコースティクス

太陽光が水面で屈折して底へ落ちる写像のヤコビアンから、面積の伸縮を出しています。

```
offset(x) ≈ -depth · c · ∇h        c = 1 - 1/n
明るさ ∝ 1 / |det(I - depth·c·H)|   H は ∇h のヘッセ行列
```

`∇²h` だけで近似する手もありますが、それだと行列式の非対角項が落ちて「丸い斑」にしかなりません。網目と尖点が出るのは det を取るからです。
3 波長ぶん別々に計算して虹の縁を出しています。実際の水の分散（n が 0.4% 違う）では 16cm の水深で見えないので、広がりは誇張してあります。

### 5. 描画（`assets/js/renderer.js`）

1. **水中パス** … 舟の底・内壁・沈んでいる金魚・沈めたポイを FBO へ。α にカメラからの距離を入れます
2. **本パス** … 空と提灯 → 舟 → 水面 → 水上の金魚 → 手元の器 → ポイ
3. **仕上げ** … 明るい所を 1/4 解像度で抜いてぼかし、足してから ACES 風にトーンマップ

水面の屈折は板ポリで近似せず、**屈折方向へ進めた点を画面に投影し直して**水中パスを読みます。採否を 0/1 で切ると金魚の輪郭で水面がブロック状に裂けるので、重みで混ぜて境目をぼかしています。

水底のコースティクスは、屈折写像のヤコビアンを `∇²h` の一次で近似したものです。波頭（`∇²h < 0`）が凸レンズになって光が集まる、という素直な形になります。

金魚は位置を持たず、**`(u, v, 部位)` だけを頂点に持たせて形は頂点シェーダで作って**います。泳ぎのうねりを毎フレーム CPU で計算して転送するのは無駄で、法線を作り直す手間も増えるためです。

## 動かす

ビルドはありません。依存パッケージもありません。

```sh
npm run dev    # http://localhost:8010/
```

ES モジュールは `file://` では読めないので、`index.html` を直接開いても動きません。

Web フォント（Google Fonts）だけ外から読んでいます。それ以外は全部この repo の中にあります。

## 必要なもの

- **WebGL2**
- **`EXT_color_buffer_float`** … 浮動小数点の FBO が作れないと FFT を解けません。無い環境ではその旨を出して止まります

線形補間が要るテクスチャは RGBA16F に寄せてあるので、`OES_texture_float_linear` には依存しません。

## いま入っていないもの

制限時間とポイの消耗は外してあります。掬う手応えだけを見たかったので、形だけ残して止めてあります（`assets/js/poi.js` と `assets/js/game.js`）。
