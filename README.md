# 金魚掬い

縁日の金魚掬い。水面を **Tessendorf の波スペクトルから GPU 上の FFT で毎フレーム逆変換**して描いています。

<https://kanade0525.github.io/kingyo-sukui/>

押している間だけポイが沈みます。金魚の下に入れてそっと持ち上げると、紙の上で跳ねているところが一拍見えてから、浮かべたお椀へ移ります。
紙は水中で速く動かすほど傷みます。破れても、少し置けば新しいポイが渡されます。

開いた時刻と、現在地の天気を映します。日が落ちると提灯に灯が入り、22 時を回ると店じまいになります。
どちらも設定（右下）から手で変えられます。

## 寸法は実物に合わせてあります

想像で作ると、質感をいくら作り込んでも「それらしい別の物」にしかなりません。画面に出る物は一つずつ実寸を調べています。

**舟** — [トロ舟（プラ舟）80L](https://search.kakaku.com/%E3%83%88%E3%83%AD%E8%88%9F%2080/)。内寸 850 × 548 × 深さ 187mm、底の外寸 807 × 500、上の外寸 911 × 602、全高 207mm。
大事なのは**垂直な箱ではない**ことで、底から上まで片側 52mm 開いた台形になっています。角には大きな R。樹脂を型から抜くための勾配と丸みなので、ここを直角に作ると板を貼り合わせた箱に見えます。

**ポイ** — 外径 83mm・内径 78mm・全長 150mm。輪は径方向に **2.5mm しかなく**、柄は 65mm。竹でも木でもなく、赤く着色したポリスチレンの一体成形です。

**金魚** — ほとんどが全長 3cm の[小赤（和金）](https://t-aquagarden.com/column/wakin)で、黒出目金と更紗出目金はまれ。和金はフナ型で細長く、出目金は琉金から出た品種なので胴が短く丸い。全長は体長の 2〜2.5 倍、つまり**尾は胴と同じくらい長い**。

**ミドリガメ** — 甲長 3cm の子ガメ。背甲は中央に[椎甲板が 5 枚、左右に肋甲板が 4 対、外周に縁甲板が 11〜12 対](https://aquaturtlium.com/turtle-shell/)。四角い板の並びで、中心から放射する線ではありません。

**浮き葉** — [スイレン](https://mikawanoyasou.org/data/suiren.htm)。直径 10〜30cm、縁から中心へ切れ込みが入り、表に光沢。舟が 83cm なので 12cm 前後にしてあります。（切れ込みが無く光沢も無い直径 30〜50cm の円は、スイレンではなくハス。）

**提灯** — [9 号長型ビニール提灯](https://www.sp-oroshi.com/blog/6.php)、直径 24cm × 高さ 53cm。

**エアレーション** — エアストーン 直径 15mm、軟質塩ビのチューブ 内径 4mm。

**お椀** — [ポリスチレン低発泡、直径 160 × 高さ 68mm](https://kingyo-sukui.easy-myshop.jp/c-item-detail?ic=Y-0005) の使い捨て。陶器ではありません（重い・割れる・高い）。屋台では[お椀を水面に浮かべて使い](https://iko-yo.net/articles/1426)、ポイを立てて水ごと流し込みます。地面に置くのではありません。

## 水面の作り

水面の高さ場は 2 つを足し合わせています。**定常な波**と、**その場で立った波紋**は性質が違うので、別々に解いています。

### 1. 定常な波 — FFT（`assets/js/ocean.js`）

Tessendorf の海面法をそのまま小さな舟に持ち込んでいます。

```
P(k) = A · exp(-1/(kL)²) / k⁴ · |k̂·ŵ|² · exp(-k²l²)      L = V²/g
h(k,t) = h0(k)·e^{iωt} + conj(h0(-k))·e^{-iωt}
ω = √(g·k·tanh(k·H))
```

- `h0` は起動時に CPU で一度だけ作ります。風速か風向を変えた時だけ作り直します
- 毎フレーム、時刻 `t` のスペクトルと choppy 変位 `Dx, Dz` を出し、**GPU のバタフライ演算で逆 FFT**します
- **MRT（`drawBuffers` 2 枚）で高さと変位 X / Z を 1 パスで同時に変換**するので、N=128 でもバタフライは 14 パスで済みます
- 分散関係には `tanh(kH)` を入れてあります。ただし引数は 10 で頭打ちにしています。実装によっては内部で `e^(2x)` を通るため、`kH > 100` で `Inf/Inf = NaN` になり、FFT 全体が壊れます

振幅は **実効「傾き」で正規化**しています。水面の見え方（反射のちらつき、底の揺らぎ、コースティクス）を決めるのは波高そのものではなく傾きなので、こちらを揃えたほうが縮尺を変えても崩れません。

Phillips は `1/k⁴` を持つので、係数 `A` の意味が波数の縮尺で何桁も変わります。海（波長 100m 級）向けの `A` をそのまま 1m の舟に使うと波が消えます。`A` には形だけ決めさせ、大きさは一度に正規化しています。

### 2. 波紋 — 波動方程式（`assets/js/ripple.js`）

FFT はスペクトルを逆変換しているだけなので、後から「ここで水を叩いた」を混ぜ込めません。波紋だけ 256² の格子で別に解いています。

```
h[n+1] = 2h[n] − h[n−1] + K·∇²h[n]
```

壁は Neumann（傾き 0）にして反射させています。たらいの中の波は端で跳ね返るので、これが無いと端で消えて嘘くさくなります。

波源はポイの出入り、金魚の身じろぎ、エアストーンの泡がはじけるところ、それに雨粒。
**雨粒と泡は、描いている粒と同じ式で位相を見て、水面に届いた瞬間に波紋を落としています。** 別々の乱数で出すと落ちた所と輪の立つ所が合わず、雨ではなく「水面がざわついている」にしか見えません。

波源は格子の刻み（4mm）より十分大きく取ります。小さいと波が格子の縦横にしか進めず、輪ではなく菱形に広がります。

### 3. 光（`assets/js/sky.js`）

時刻（0〜24 の実数）と天気を渡すと、太陽の高度・方位・色、空の三色、提灯の強さ、霞み、露出が決まります。

**昼** は太陽ひとつ。方向の揃った光でないと、水底のコースティクスも水面のきらめきも芯が出ません。
**夕方から夜** は提灯が主役になります。9 号長型を画面の左右に 1 つずつ、水面から 1.05m に吊るしてあります。薄明は地平の下 14° まで引いてあり、空が焼けているあいだに灯が入ります。
**22 時過ぎ** から提灯が落ちて、23 時半には消えます。そこから先は露出も持ち上げないので、ほとんど何も見えません。ポイも片付けられていて、水面をなでることしかできません。

**曇りと雨** では直射が雲で散って方向を失うので、コースティクスも水面のきらめきも同時に消えます。手加減ではなく、曇りの日に水底の網目が出ないのと同じことです。そのぶん露出は持ち上げないと、昼の雨がただの夕方になります。

天気は現在地を聞いて [Open-Meteo](https://open-meteo.com)（鍵の要らない公開 API）から引きます。外へ出るのは緯度経度を小数 2 桁（約 1km の粗さ）に丸めたものだけで、断られれば晴れのまま動きます。

屋台の向きは 14° 回してあります。0° だとほぼ真上から覗く構図で太陽の照り返しが水面の中央に座り、白い靄で底が見えなくなります。95° では必要な水面の傾きが 10σ になって、きらめきが一度も起きません。

### 4. 水底のコースティクス

太陽光が水面で屈折して底へ落ちる写像のヤコビアンから、面積の伸縮を出しています。

```
offset(x) ≈ +depth · c · ∇h        c = 1 - 1/n
明るさ ∝ 1 / |det(I + depth·c·H)|   H は ∇h のヘッセ行列
```

符号は `refract()` で確かめてあります。逆にすると、尖った波頭の下に細い筋が出るかわりに広い谷の下に太いぼやけた斑が出て、波紋のリングでは明暗がそっくり裏返ります。

`∇²h` だけで近似する手もありますが、それだと行列式の非対角項が落ちて「丸い斑」にしかなりません。網目と尖点が出るのは det を取るからです。
3 波長ぶん別々に計算して虹の縁を出しています。実際の水の分散（n が 0.4% 違う）では 15cm の水深で見えないので、広がりは誇張してあります。

明るさは水面の曲率に比例するので、波を低くすると素直に消えます。物理としては正しいのですが、「波の高さ」のつまみを下げただけで水底の網目まで無くなるのは意図と違うので、波の高さで割り戻しています（0.75 乗なので、波を上げれば網目も強くなります）。

### 5. 描画（`assets/js/renderer.js`）

1. **水中パス** … 舟の底・内壁・エアストーン・沈んでいる金魚・ポイ・お椀を FBO へ。α にカメラからの距離を入れます
2. **本パス** … 空と提灯 → 舟 → 水面 → 浮き葉 → 泡と飛沫と雨 → 水上の金魚 → お椀 → ポイ
3. **仕上げ** … 明るい所を 1/4 解像度で抜いてぼかし、足してから ACES 風にトーンマップ、フィルムの調子、FXAA

水面の屈折は板ポリで近似せず、**屈折方向へ進めた点を画面に投影し直して**水中パスを読みます。採否を 0/1 で切ると金魚の輪郭で水面がブロック状に裂けるので、重みで混ぜて境目をぼかしています。

屈折に使う傾きは細かい波をならしたものです。実際の浅い水で底の像を動かすのは大きなうねりで、cm 級のさざ波は照りに出るだけで像をほとんど動かしません。全部の波を同じように屈折へ入れると、隣り合う画素が遠く離れた所を拾い、金魚の胴が途中で切れて二匹に見えます。

金魚・亀・浮き葉は位置を持たず、**`(u, v, 部位)` だけを頂点に持たせて形は頂点シェーダで作って**います。泳ぎのうねりを毎フレーム CPU で計算して転送するのは無駄で、法線を作り直す手間も増えるためです。

輪郭のぎざぎざは FXAA でならしています。MSAA は使っていません。多重サンプルのレンダーバッファを普通のテクスチャへ blit する必要があり、タイル式の GPU（Apple Silicon など）でその blit が化けて、縁に点線状のノイズが乗るためです。

### 6. 汚し（`assets/shaders/common.js`）

新品そのままの面が並ぶと、どれだけ質感を作り込んでも「CG で置いた物」に見えます。実物が実物に見えるのは、汚れが**物の形に沿って**出るからで、乱数のノイズを上から掛けても汚しにはなりません。

縁日の道具に実際に出る 5 つを部品にしてあります。強さは `uWear` でまとめて動かせます。

- **垢** … 凹んだ所・隅・継ぎ目に溜まる
- **摩耗** … 角と、手や物が当たる所の色が抜ける
- **流痕** … 水が流れた跡が縦に残る
- **水垢** … 乾いた水滴の輪が白く残る
- **擦過** … 細かい傷が向きを揃えて走る

垂直な面の模様を `xz` だけで取ると、高さ方向にいっさい変化せずのっぺりします。壁では「壁に沿った横の距離」と「高さ」で取っています。

### 7. 音（`assets/js/sound.js`）

ほとんどはその場で合成しています。聞こえるのは「その場にあるもの」だけです。

| | |
| --- | --- |
| いつでも | エアポンプの泡、ポイが水に触れる音 |
| 日中 | 蝉（あぶらぜみ・みんみんぜみ）、ときどき風鈴 |
| 夕方から | 祭囃子（篠笛・締太鼓・鉦）と人のざわめき |
| 夜 | そこに虫の声が重なる |
| 店じまい後 | 虫の声だけ |
| 雨 | 地鳴りと、粒が水面を打つ音 |

泡のはじける音は、気泡の共振（Minnaert）が上向きに掃引する正弦。半径 1.5mm で約 2.2kHz。掃引を外すと電子音になります。
ミンミンゼミは「ミーン」で立ち上がり 4.6Hz で刻み「ミー」と下がる三段。この形が無いと、ただの唸りになります。
祭囃子は遠くから流れてくる想定なので、低域通過と残響を強めに掛けています。近くで鳴らすと合成だと分かりますが、遠ければ輪郭だけで通ります。

蝉と風鈴だけ、CC0 の録音も入れてあります（設定から切り替え）。出どころと、種類が違うことについては [`assets/sound/CREDITS.md`](assets/sound/CREDITS.md) に書いてあります。
音を聴き比べるには [`sound.html`](https://kanade0525.github.io/kingyo-sukui/sound.html) を開いてください。

## 動かす

ビルドはありません。依存パッケージもありません。

```sh
npm run dev      # http://localhost:8010/
npm run stamp    # 配る前に、import に版を押す
```

ES モジュールは `file://` では読めないので、`index.html` を直接開いても動きません。

GitHub Pages は `cache-control: max-age=600` を返すので、更新したときに新しい `index.html` と古い JS が混ざります。`npm run stamp` が全ての相対 import に `?v=<時刻>` を押して、それを防いでいます。

性能を実機で測るには [`perf.html`](https://kanade0525.github.io/kingyo-sukui/perf.html) を開いてください。各パスの所要時間とフレームレートを出します。

Web フォント（Google Fonts）だけ外から読んでいます。それ以外は全部この repo の中にあります。

## 必要なもの

- **WebGL2**
- **`EXT_color_buffer_float`** … 浮動小数点の FBO が作れないと FFT を解けません。無い環境ではその旨を出して止まります

線形補間が要るテクスチャは RGBA16F に寄せてあるので、`OES_texture_float_linear` には依存しません。
