# 金魚掬い

縁日の金魚掬いと、掬った金魚を持ち帰る縁側。ブラウザだけで動きます。

**<https://kanade0525.github.io/kingyo-sukui/>**

押している間だけポイが沈みます。金魚の下に入れてそっと持ち上げると、紙の上で跳ねているところが一拍見えてから、浮かべたお椀へ移ります。紙は水中で速く動かすほど傷み、**水から出した瞬間に金魚の重さが全部乗ります**。一度にたくさん乗せると、お椀へ移すまでの一拍を持ちこたえられません。破れても、少し置けば新しいポイが渡されます。

器に金魚がいると「持ち帰る」が出ます。押すと家の縁側へ移り、ガラスの金魚鉢で泳ぎはじめます。**この端末に残る**ので、閉じて開き直しても居ます。

開いた時刻と現在地の天気を映します。日が落ちると提灯に灯が入り、21 時を回ると店じまい。どちらも画面下の並びから手で変えられます。日本語以外のブラウザでは英語になります。

---

## 何がすごいか

**水面が絵ではなく、毎フレーム解いた波です。**
海洋学の波スペクトル[^spectrum]を GPU 上の FFT[^fft] で逆変換して、256×256 の高さを毎フレーム作り直しています。風を強めれば波が高くなり、うねりの向きも変わります。

**水底の網目が、その波から出ています。**
コースティクス[^caustics]を模様として貼るのではなく、水面の傾きから光がどこへ集まるかを計算しています。だから波を止めれば網目も止まり、空が曇れば網目も消えます。

**太陽が本物です。**
日付と緯度経度から太陽の高度と方位を出しています。夏至の夕方は日が長く、冬は短い。現在地の天気も [Open-Meteo](https://open-meteo.com) から引いて、晴れ・曇り・雨を絵に出します。

**金魚鉢がガラスです。**
鉢越しに見る金魚は、屈折[^refract]でゆがんで大きく見えます。背景を別の板に描いてから、ガラスの面の傾きぶんだけ読む位置をずらしています。

**全部で 1MB ちょっと、ビルドなしです。**
依存パッケージはゼロ。npm install も webpack もありません。ES モジュールと GLSL だけです。

## こだわったところ

### 寸法は実物を調べてから決めた

想像で決めた寸法は、だいたい間違っています。実際に何度も間違えました。

- ポイは **直径 7.5cm・枠は 7 号（約 7mm）**。最初に 9cm で作ったら、画面の中で団扇に見えました
- 舟は **1.0m × 0.62m・水深 25cm**。縁日の金魚すくいは「舟」と呼ばれる浅い箱です
- **紙に乗る判定を、紙より大きく取っていました。** 直径 78mm の紙に対して直径 105mm の輪で拾っていたので、紙に触れてもいない金魚まで乗りました。縦の窓も 125mm あり、金魚の泳ぐ層（68mm）より広かったので、ポイを上げる間に層ぜんぶを拾っていました。**一度に 14 匹**乗ることがあったのはこれが理由です。紙の実寸に直し、乗る量にも上限を置きました（3cm の小赤で 3 匹、出目金なら 1〜2 匹）
- 掬った金魚を入れる器は[**低発泡ポリスチレンの成形品**](https://kingyo-sukui.easy-myshop.jp/c-item-detail?ic=Y-0005)。肉厚を 11mm で作っていましたが、直径 15cm の器に 1cm の縁は擂鉢の厚みで、縁日のお椀ではありません。**2.5mm** に直しました
- 金魚鉢は **直径 20cm × 高さ 19.5cm・4.8L**。3cm の小赤で 2〜3 匹が目安なので、12 匹持ち帰ると実物の 4〜6 倍の密度になります。断りはしませんが「鉢に 12 匹（目安は 3 匹）」と数で出します
- 底砂は[大磯砂](https://t-aquagarden.com/column/bottomsand_guide)を 3cm。水草は[アナカリス](https://ja.wikipedia.org/wiki/オオカナダモ)で、葉は長さ 1.5〜3.5cm・幅 2〜4mm、節ごとに 3〜6 枚が輪生します
- 子ガメは[ミシシッピアカミミガメ](https://www.pref.kanagawa.jp/docs/a4y/images/misisippiakamimigame.html)。幼体の甲羅が明るい緑だから「ミドリガメ」です

### 縁側の外は露地（ろじ）[^roji]にした

三大景物（飛び石・石灯籠・蹲踞[^tsukubai]）に建仁寺垣[^kenninji]・杉苔・楓。垣の向こうには遠くの山を重ねています。

置き場所は**画角から決めました**。カメラの目の高さが鉢に合わせて 23cm しかないので、庭の地面は縁側の縁に遮られて 1.8m 先からしか見えません。飛び石を奥へ真っ直ぐ並べると、見える分は鉢の真後ろに隠れます。見える帯を斜めに横切らせているのはそのためです。

### 縁側に物を置いた

板が広いだけの縁側は、拭き上げた展示室にしか見えません。夏の縁側には必ず何か置いてあります。

蚊遣り（[渦巻は直径 12cm](https://www.kincho.co.jp/seihin/qa/qa_uzumaki.html)、線香皿 17cm。先だけ熾って灰が白く残り、煙が立ち上ります）、団扇（平柄、面の幅 24cm）、[沓脱石](https://www.niwaishi.co.jp/blog/column121/)と下駄。
縁甲板には 30mm の厚みがあります。床を面一枚で終わらせていたので、縁側が厚みの無い板きれでした。

蚊遣りは三度作り直しました。はじめは板に貼った絵で、平らな丸にしか見えませんでした。次に陶器の豚で組みましたが、軸に沿った楕円体と棒だけではどう並べても豚に見えず、煙の穴は目玉に見えました。三度目は皿に渦を刷りましたが、今度は厚い円盤に模様が付いているだけでした。

線香は太さ 3.4mm の棒を巻いた立体で、色は深緑です。渦は「1 周するごとに 6.8mm だけ外へ出る螺旋」なので、半径から角度ぶんを引いて割った余りから、いちばん近い巻きまでの距離が出せます。薄い層の中を光線で進めて当たりを取っています。燃えるのは外の端から渦に沿ってなので、灰は半径ではなく巻き数で切ります（半径で切ると、渦が輪切りの点線になります）。

団扇も同じ躓き方をしました。丸い板の真ん中から筋を引いていたので、風車にしか見えなかった。実物は卵形で、骨は柄の先の「要」という一点から扇に開きます。面のいちばん太い所で骨が 45 本・間隔 5mm。柄は丸棒ではなく幅 2cm・厚さ 3mm の竹の板で、丸棒にすると爪楊枝に見えます。

置き場所も間違えました。縁側の板があるのは縁より手前だけなのに、その外へ置いて宙に浮かせていました。いまは単体試験で見ています。

### 使われた物として汚した

下ろしたての物は、作り物にしか見えません。

- 鉢のガラスに、水位の跡の白い水垢、乾いた硬水の斑点、内側の水面際の緑の膜、上面の埃
- 石灯籠と蹲踞に、雨の溜まる上面と地面から湿りの上がる足元と日の回らない側の苔、白緑の地衣[^lichen]、笠の下へ落ちる水の跡。飛び石だけは踏まれるので苔を抑える
- 掬われた金魚に、網と手で飛んだ鱗の剥げと、条に沿って縁から裂けた尾びれ
- 刈り込みのサツキに、[刈り込みばさみの切り口](https://www.sharing-tech.co.jp/sentei/satsuki-sentei/)が褐色に枯れて残る跡と、日の当たらない下枝の枯れ上がり

### 耳で判断できないものは測った

音は聞いて直せないので、画面に出る音量を実測して合わせました。揃える前は深夜だけ 11dB 低く沈んでいました。虫の音だけ係数が 2.0 と大きいのは、鳴き声が 4〜5kHz に偏っていて、LUFS[^lufs] が人の耳に合わせてその辺りを重く数えるためです。

家では屋台の音が鳴りません。エアポンプは舟に沈めてある物なので、家まで聞こえる道理がない。人のざわめきも同じ。祭囃子だけは、縁側まで遠く流れてきます。

### 絵は必ず描いて目で見た

試験が通ったことは、見たことになりません。実際、試験は全部通ったまま次のことが起きていました。

- 砂利の面がメッシュに有るのに**一度も画面に出ていなかった**。描き先と読み先に同じ板を渡していて、WebGL がフィードバックと見なして描画ごと捨てていた
- 石の苔が**見える面に一つも付いていなかった**。「北側」を -z に取っていたが、カメラが見るのは +z 側
- 石灯籠の部材が**全部わずかに浮いていた**。竿と中台の間に 1.1cm、中台と火袋の間に 5.7cm
- 亀の背甲と腹甲の縁の高さが違って、甲羅のまわりに**3mm の隙間が一周していた**
- 楓の葉の透過光[^translucent]の**符号が逆**で、太陽を背にしたときに光っていた

### 真夏の日向にした

屋台（画面の平均輝度 126）に対して家が 69 しかなく、同じ晴れの昼とは思えない暗さでした。測って原因を潰しています。

苔の反射率を 0.03〜0.056（ほとんど黒）で取っていたのが一つ。庭には**落ちる影が無く**、足元の暗がりだけだったのがもう一つ。カンカン照りが分かるのは明るさではなく、落ちる影の濃さと輪郭のほうです。

縁側は南を向くので、座って庭を見ると**いつも逆光**になります。こちらを向いた竹垣の面に直射は当たりません。明るいのは開けた空から回り込む光と、焼けた地面の照り返しのため。葉は薄いので裏から透けて黄緑に光る——これが真夏の庭の見え方を決めています。

### 時刻のつまみに、その日の空の色を敷いた

つまみだけだと、どこが昼でどこが夜か動かすまで分かりません。0 時から 24 時までの空の色を帯にして敷いてあります。提灯に灯が入ってから店じまいまでが「お祭り」の帯で、その日のどこが縁日なのかが分かります。帯の色は画面と同じ `sunFor` から引いているので、必ず一致します。

### 天気と時刻は、設定を開かなくても触れる

設定（右下）は開発用の覗き窓で、いずれ畳みます。遊ぶ人が触りたいのは音の入切と、天気と時刻の三つだけなので、下の並びに出しています。天気のボタンは晴れ → 曇り → 雨 → 現在地の順に回り、時計のボタンで時刻の帯が開きます。つまみは設定側と同じ値を指します。

### 書体は一つだけ

見出しに解星デコール、本文にゴシックを当てていたので、画面の中に書体が三つ並んでいました。昭和の縁日という題材に対して、字だけが現代の顔をしていた。しっぽり明朝 B1 の一本に絞り、太さも覆いの題字に揃えました。

### 操作のほうは刷り物にした

画面の中は実物どおりに作ってあるのに、ボタンだけが 2020 年代の顔をしていました。白い丸角のピル、ふわっとした影、背景のすりガラス。どれも 2010 年代以降の画面の作法です。

色を四つに絞りました。**生成り（わら半紙）・墨・藍・朱**。昭和の刷り物が四色なのは味ではなく版が四枚だったからで、色数を減らすことでしか出ない顔があります。角を立て、影は硬く落とし、縁は二重の罫で囲みました。つまみは丸い玉ではなく、帯に挿した栞の形です。

レトロにするために読みにくくするのは別の話なので、地と字の明暗差は落としていません（生成り `#f1e8d5` と墨 `#2a2420`）。紙の繊維は SVG を CSS に埋めてあるので、外へは何も取りに行きません。

画面の中が写実で、操作が紙。これは手を抜いた結果ではなく、屋台の品書きが紙であるのと同じ関係です。

## 中身

| ファイル | 受け持ち |
| --- | --- |
| `assets/js/ocean.js` | FFT の水面 |
| `assets/js/ripple.js` | 波紋。波動方程式[^wave]を格子で解く |
| `assets/js/sky.js` | 太陽の位置・空の色・露出・天気 |
| `assets/js/renderer.js` | 描画の段取り |
| `assets/js/world.js` | 実物の寸法。ここだけ読めば大きさが分かる |
| `assets/js/home.js` | 家の鉢。`localStorage` を触る唯一の場所 |
| `assets/js/sound.js` | 音の層と音量 |
| `assets/js/ui.js` | DOM を触る唯一の場所 |
| `assets/shaders/` | GLSL |

試験は 127 件（単体 58・通し 69）。枠組みは入れていません。「名前と関数の並び」を順に呼んで、投げたら落ちた、で足ります。

```sh
npm test          # 全部
npm test unit     # ブラウザを使わない分だけ。速い
npm run dev       # http://localhost:8010/
npm run stamp     # 配る前に、import に版を押す
```

GitHub Pages は `cache-control: max-age=600` を返すので、更新すると新しい `index.html` と古い JS が混ざります。`npm run stamp` が全ての相対 import に `?v=<時刻>` を押して、それを防いでいます。

実機で性能を測るには [`perf.html`](https://kanade0525.github.io/kingyo-sukui/perf.html) を開いてください。

**必要なもの**: WebGL2 と `EXT_color_buffer_float`（浮動小数点の FBO[^fbo] が作れないと FFT を解けません）。無い環境ではその旨を出して止まります。

## 用語

[^spectrum]: **波スペクトル** — 海の波を「どの向きへどれくらいの波長の波がどれだけ混ざっているか」で表したもの。ここでは Phillips スペクトルに、風向きから外れた波を落とす補正を掛けています。
[^fft]: **FFT（高速フーリエ変換）** — 「波の混ざり具合」から「実際の高さの地図」へ一気に変換する計算。256×256 を素直に計算すると 1 フレームに 43 億回かかりますが、FFT なら 52 万回で済みます。
[^caustics]: **コースティクス** — 水面で曲がった光がプールの底に作る、揺れる網目模様のこと。
[^refract]: **屈折** — 光が水やガラスに入るときに曲がること。ガラス越しの金魚がゆがんで見えるのはこれです。
[^translucent]: **透過光** — 葉のような薄い物を裏から光が通り抜けて、表から見ると光って見えること。逆光の木がきれいなのはこれです。
[^wave]: **波動方程式** — 波がどう広がるかを表す式。石を落としたときの輪が広がる動きがこれです。
[^fbo]: **FBO（フレームバッファオブジェクト）** — 画面ではなく、計算結果をしまっておく板。ここに波の高さを書いて、次の段で読みます。
[^lufs]: **LUFS** — 音の大きさの単位。人の耳が敏感な帯域を重く数えるので、「同じ音量」に揃えるのに使います。
[^roji]: **露地（ろじ）** — 茶室へ向かう庭のこと。飛び石・石灯籠・蹲踞を三大景物と呼びます。
[^tsukubai]: **蹲踞（つくばい）** — 茶室に入る前に手を清める、低く据えた手水鉢。しゃがんで使うのでこの名前です。
[^kenninji]: **建仁寺垣（けんにんじがき）** — 割った竹を隙間なく立てて並べ、横に渡した胴縁で押さえた竹垣。
[^lichen]: **地衣（ちい）** — 菌と藻が一緒に暮らしている生き物。古い石に白緑の輪になって張り付きます。
